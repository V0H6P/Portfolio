Statistical Arbitrage Engine

September 2024
Python Kalman Filter Cointegration Backtesting

Overview

This project implements a cointegration-based pairs trading strategy with dynamic hedge ratio estimation using the Kalman filter. The system identifies statistically co-moving asset pairs and exploits temporary divergences from equilibrium relationships.

Methodology

The strategy operates in three distinct phases: pair identification through Engle-Granger cointegration testing, dynamic hedge ratio estimation via a state-space model, and signal generation based on z-score thresholds of the spread residuals.

  • Cointegration testing with Augmented Dickey-Fuller and Johansen procedures
  • Kalman filter for online hedge ratio estimation with time-varying parameters
  • Adaptive z-score thresholds calibrated to rolling volatility
  • Transaction cost modeling including slippage, commissions, and market impact

Implementation

The system is implemented in Python with a modular architecture separating data ingestion, signal generation, position management, and risk controls. Key components include:

class KalmanHedgeRatio:
    def __init__(self, delta=1e-4, ve=1e-3):
        self.delta = delta
        self.ve = ve
        self.theta = np.zeros(2)
        self.P = np.eye(2)
        self.R = np.zeros((2, 2))

    def update(self, x, y):
        F = np.array([[x, 1.0]])
        self.R = self.P + self.delta * np.eye(2)
        yhat = F @ self.theta
        et = y - yhat
        Qt = F @ self.R @ F.T + self.ve
        Kt = self.R @ F.T / Qt
        self.theta = self.theta + (Kt * et).flatten()
        self.P = self.R - Kt @ F @ self.R
        return self.theta[0], et, Qt

Results

Backtested on US equity data from 2010 to 2024, the strategy achieves a Sharpe ratio of 1.84 with maximum drawdown of 8.2%. The Kalman filter approach demonstrates significant improvement over static OLS hedge ratios, particularly during regime transitions.

  • Annualized return: 12.3%
  • Sharpe ratio: 1.84
  • Maximum drawdown: 8.2%
  • Win rate: 61.4%
  • Average holding period: 4.7 days

Key Findings

The adaptive hedge ratio significantly reduces drawdowns during structural breaks compared to rolling-window OLS estimation. The Kalman filter's ability to weight recent observations more heavily provides faster adaptation to changing market conditions while maintaining numerical stability.

Future work includes extending the framework to multi-asset cointegration using the Johansen procedure and incorporating transaction cost optimization in the signal generation layer.
